# مداني

**مداني** لغة برمجة عربية بأسلوب Python. تكتب الكود بكلمات عربية، ويُترجم إلى JavaScript فيعمل في المتصفح وعلى الخادم.

```
صنف حيوان:
    دالة بناء(اسم):
        هذا.اسم = اسم
    دالة تكلم():
        اطبع(هذا.اسم, "يصدر صوتاً")

لكل ي في مدى(1, 4):
    اذا ي % 2 == 0:
        حيوان("شيء " + نص(ي)).تكلم()
```

> المشروع في مرحلته الأولى. الملاحظات والاقتراحات مرحّب بها.

## التجربة السريعة

جرّب المحرر من المتصفح، بدون تثبيت أي شيء: https://claude.ai/artifact/T9rqJXNXb9gg5ZTLnZvNHf

## التثبيت والتشغيل

المتطلبات: Python 3 و Node.js.

```
python madani.py run hello.mdn              # تشغيل برنامج
python madani.py build web.mdn --html       # إنشاء صفحة ويب كاملة
python madani.py build server.mdn           # إنشاء ملف .mjs
```

امتداد ملفات اللغة: `.mdn`

## مرجع اللغة

| ما تريده | مداني |
|---|---|
| شرط | `اذا` / `والا اذا` / `والا` |
| حلقات | `طالما` ، `لكل س في ...` ، `توقف` ، `استمر` |
| دالة | `دالة جمع(أ, ب):` ثم `ارجع أ + ب` |
| دالة مجهولة | `دالة(س): س ** 2` |
| صنف | `صنف قط(حيوان):` مع `بناء` و`هذا` و`الاب` |
| قيم | `صحيح` ، `خطأ` ، `لاشيء` |
| منطق | `و` ، `او` ، `ليس` ، `س في قائمة` ، `س ليس في قائمة` |
| شرط مختصر | `"ناجح" اذا د >= 50 والا "راسب"` |
| أخطاء | `حاول:` / `استثناء خ:` / `اخيرا:` / `ارفع` |
| غير متزامن | `غير_متزامنة دالة ...` و `انتظر` |
| متغير عام | `عام س` داخل الدالة |
| كائن جديد | `جديد تاريخ()` |

التعليقات بعلامة `#`. الفاصلة العربية `،` والأرقام الهندية `٣` مدعومة.

## الدوال المدمجة

**عامة:** `اطبع` `نص` `عدد` `طول` `مدى` `اقرأ` `جذر` `ارضية` `سقف` `تقريب` `مطلق` `اكبر` `اصغر` `عشوائي` `قوة` `مفاتيح` `قيم` `عناصر` `جيسون.حول` `جيسون.حلل` `بعد` `كرر_كل` `انتظار` `جلب`

**القوائم:** `.اضف` `.احذف_اخر` `.احذف_اول` `.رتب` `.اعكس` `.اربط` `.شريحة` `.يحتوي` `.خريطة` `.رشح` `.لكل_عنصر` `.ابحث`

**النصوص:** `.كبير` `.صغير` `.قسم` `.استبدل` `.يحتوي` `.يبدأ_ب` `.ينتهي_ب` `.نظف`

**الويب:** `عنصر("#معرف")` ، `كل_العناصر` ، `انشئ_عنصر` ، `ارسم(html)` ، وعلى العناصر: `.نص` `.محتوى` `.قيمة` `.عند("نقر", دالة)` `.اضف_ابن` `.اخف` `.اظهر`

**الخادم (Node.js):** `انتظر خادم(3000, معالج)` حيث المعالج دالة تستقبل `طلب` (فيه `مسار` و`طريقة` و`جسم`) وتُرجع نصاً أو كائناً.

## أمثلة

- `editor.html`: المحرر (يعمل بفتحه في المتصفح)
- `hello.mdn`: أساسيات اللغة والأصناف والأخطاء
- `web.mdn`: عدّاد وقائمة مهام تعمل في المتصفح
- `server.mdn`: خادم وAPI

## كيف تعمل

`madani.py` يقرأ الكود فيمرّ بثلاث مراحل: محلل لغوي (يدعم المسافات البادئة) ثم محلل نحوي يبني شجرة البرنامج ثم مولّد يكتب JavaScript. يُضاف أعلى كل برنامج ملف تشغيل صغير فيه الدوال العربية المدمجة.

## قيود معروفة

- لا يوجد نظام وحدات (`استورد`) بعد.
- لا توجد قوالب نصوص مثل `«مرحبا {اسم}»` بعد.
- القوائم الفارغة تُعدّ صحيحة في الشروط (سلوك JavaScript وليس Python).
- لا يوجد تلوين للكلمات في المحرر.
